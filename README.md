# Casio_-_PV-2000

Thumbnails for Casio PV-2000 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `pv2000` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
